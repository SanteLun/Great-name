# Опубликованные результаты

Компактная копия результатов отчёта и презентации. Итоговый прогнозный прогон:
`outputs/full_audited`, 2190 МО, 24 месяца; Prophet — до 40 серий.
`forecast_common_summary.csv` сравнивает модели на пересечении с Prophet,
`forecast_panel_common_summary.csv` — модели полной панели.

- `forecasting/`: метрики, покрытие, bootstrap, история выбора и манифесты.
- `detectors/`, `changepoint/`, `diffusion/`: синтетические проверки.
- `news/`: отдельный эксперимент на 80 МО.
- `foundation/`: параметры и отпечатки checkpoint.
- `future/`: происхождение будущего прогноза без оценки по фактам.

Манифесты сохранены без переписывания исторических путей и хешей. Они описывают
исходные эксперименты, а не новое обучение текущей версии. Промежуточные
прогоны не включаются в Git; их параметры остаются в манифестах. Для новых результатов
выполните конвейер заново. Подробные прогнозы и исходные данные в публикацию не входят.
Атрибуция и условия производных данных: [DATA_LICENSES.md](../../DATA_LICENSES.md).
