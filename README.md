# Прогноз потребления и обнаружение структурных изменений

Решение задания СберИндекса: прогноз расходов муниципалитетов на 1, 3, 6 и 12 месяцев,
сравнение моделей и обнаружение структурных изменений. Три набора: расходы,
доступность рынков и транспортные связи. История: 2023–2024, 2190 МО, 6 категорий.

## Материалы

- [Методологический отчёт](reports/методологический_отчёт.md).
- [HTML-презентация](reports/презентация/index.html): откройте вместе с папкой `assets`.
- [Таблицы и манифесты](reports/results/README.md).
- [Методология](SOLUTION.md), [матрица требований](CONTEST_COMPLIANCE.md).
- [Источники и условия использования](DATA_LICENSES.md).

В сохранённом полном прогоне общая сезонность имеет MAE 420,14 на месяц и 1070,94
на год против 488,45 и 2884,65 у Prophet на совпадающих фактах. На 3 и 6 месяцах
лучше Prophet. Месячный bootstrap-интервал разности включает ноль; годовой тест
имеет один cutoff. Подготовка публикации не включала повторное обучение текущего кода.

Реализованы наивные модели, общая сезонность, модель короткой истории, LightGBM,
CatBoost, Prophet, Chronos-Bolt Tiny, причинный ансамбль и выбор модели.
Валидация использует точные горизонты и наблюдаемые факты. Детекторы:
CUSUM/BOCPD онлайн, PELT/BinSeg офлайн. Отдельный эксперимент с новостями ЦБ
ухудшил MAE 504,83 → 557,32; положительный эффект не заявляется.

## Установка

Команды выполняются из корня проекта. Основной код проверен на Python 3.14.3;
минимальная заявленная версия — Python 3.10.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Для повторения версий проверенного окружения вместо `requirements.txt` используйте
`requirements-lock.txt`. Это фиксация прямых зависимостей, не полный транзитивный lock.
Для Chronos дополнительно установите `requirements-foundation.txt`. Первая загрузка
весов требует сети; расчёт выполняется локально.

## Данные

Получите наборы по ссылке в DATA_LICENSES.md и разместите:

```text
data/hackathonlicence/consumption.parquet
data/hackathonlicence/market_access.parquet
data/hackathonlicence/connection.parquet
```

Пути заданы в `configs/data.yaml`. Исходные данные, обработанная панель, веса
и подробные прогнозы исключены из Git. Лицензионный PDF и небольшой
корпус официальных заголовков ЦБ включены.

## Запуск

Быстрая проверка на 80 МО без Prophet и загрузки весов:

```powershell
python scripts/run_pipeline.py --prepare --territories 80 --quick --skip-prophet
```

Полный конвейер после установки зависимостей Chronos:

```powershell
python scripts/run_pipeline.py --prepare --chronos
```

Для повторного получения новостей добавьте `--collect-news` (требует сети).
Конвейер создаёт результаты в `outputs/validated`, `outputs/improved`, `outputs/final`
и обновляет отчёт с презентацией. Он не воспроизводит побитово старое объединение
независимых экспериментов: их параметры сохранены в `reports/results`.
Эта папка — фиксированный снимок публикации, автоматически не обновляется.

Будущие прогнозы после нового конвейера:

```powershell
python scripts/11_forecast_future.py --source outputs/final --output-dir outputs/future
```

Prophet требует рабочего CmdStan. При блокировке временных файлов на Windows
запускайте из обычного терминала либо используйте `--skip-prophet`.
Без Prophet новое сравнение с ним отсутствует.

## Ограничения

История составляет 24 месяца. В годовом holdout LightGBM/CatBoost используют
помеченный резервный прогноз из-за отсутствия обучающих пар. Prophet проверен
на подвыборке. Раннее предупреждение реальных будущих шоков не подтверждено
независимой разметкой. Фактический лаг публикации расходов неизвестен.
Подробности и проверка интервалов приведены в отчёте.
